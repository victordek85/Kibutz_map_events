# טיוטה: בקשה למנהל/ת מערכת מרום (שלב 2)

> טיוטה לשליחה. להשלים את [הסוגריים] לפני השליחה.

---

**נושא:** הזמנת ייצוא שכבת "נכסים" של קיבוץ [שם הקיבוץ]

שלום [שם],

אנחנו בונים לקיבוץ [שם הקיבוץ] כלי פנימי פשוט לשליחת הודעות לחברים: מסמנים על מפה את הבתים או הכבישים שהודעה נוגעת להם (הפסקת מים, עבודות, חסימת כביש), ושולחים תמונה בקבוצת הווטסאפ של הקיבוץ.

כדי שהמפה תראה את המגרשים והבתים כמו שהחברים מכירים אותם, נשמח להזמין מכם **ייצוא חד־פעמי של שכבה אחת**, בתשלום, לפי הפרטים:

**השכבה:** "נכסים" של הקיבוץ (במערכת שלנו: [שם השכבה, למשל kibbutz_nehasim]).

**כל הישויות בשכבה:** כל המגרשים והמבנים, כולל אלה בלי שם דייר או בלי מספר.

**השדות שאנחנו צריכים, ורק הם:**

| שדה | תוכן |
|---|---|
| הצורה (גאומטריה) | פוליגון של המגרש או המבנה |
| NUM | מספר הבית / המגרש |
| DAYAR | שם הדייר או המשפחה (או שם המבנה הציבורי) |
| MAKOR | סוג: מגרש או מבנה |
| GUSH | גוש |
| HELKA | חלקה |
| ORIG_ID (או מזהה קבוע אחר) | כדי שנוכל לעדכן בהמשך בלי כפילויות |

שדות אחרים (ארנונה, מונים, הערות, פינוי וכו') **לא נחוצים לנו, ועדיף שלא יופיעו בקובץ.**

**פורמט:** GeoJSON (עדיף) או Shapefile מלא (‎.shp, .shx, .dbf, .prj‎) בקידוד UTF-8, כדי שהעברית תישמר.

**מערכת קואורדינטות:** WGS84 (EPSG:4326) עדיף. ITM (רשת ישראל החדשה, EPSG:2039) גם מתאים, ובלבד שקובץ ה־‎.prj‎ מצורף.

**שאלות:**
1. מה העלות, ובכמה זמן אפשר לקבל את הקובץ?
2. האם אפשר להזמין עדכון של אותה שכבה בעתיד (למשל פעם בשנה), ובאיזו עלות?
3. האם יש מגבלות שימוש בנתונים? אנחנו מתכננים להציג אותם רק לחברי הקיבוץ, באתר שלא מופיע במנועי חיפוש ו[מוגן בסיסמה / באישור מזכירות הקיבוץ].

הנתונים ישמשו רק את הכלי הזה. לא נעביר אותם לאחרים ולא נעלה אותם ל־OpenStreetMap או לשום מאגר ציבורי.
